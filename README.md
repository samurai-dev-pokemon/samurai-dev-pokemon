### 🚀 Latest Project — Samurai Anime

<div align="center">

**A full-stack anime streaming platform** with live episode tracking, cloud-synced watchlists, and real-time community comments — built solo from the ground up (except the api I stole it thanka to SH0MIK).

</div>

| | |
|---|---|
| 🎬 **What it is** | An anime streaming site with per-episode watch progress, sub/dub switching, multiple server fallback, and a native custom video player |
| 💬 **Latest feature** | Real-time comments — spoiler-blurred replies, likable comments/replies, per-episode & per-anime threads, Enter-to-post |
| ☁️ **Backend** | Firebase Auth + Firestore, live `onSnapshot` listeners for watchlist/progress/reactions synced across devices |
| 🔐 **Security** | Hand-written Firestore rules validating every write (including atomic like-toggle rules that only let you touch your *own* like, nothing else) |
| 🎨 **Frontend** | React + TypeScript + Tailwind, fully custom UI kit (no component library) |

```
📁 Samurai-Anime/
 ├─ Custom video player (HLS/MP4/embed modes, intro/outro skip)
 ├─ Cloud-synced continue-watching + watchlist
 ├─ Like/dislike system with atomic Firestore transactions
 └─ Real-time comments with spoilers, replies & likes
```
